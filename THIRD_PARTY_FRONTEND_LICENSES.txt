kxy frontend runtime dependency notices
========================================

The production frontend is distributed as prebuilt JavaScript under
frontend/dist. This file keeps the notices readable without shipping
frontend/node_modules or dependency source trees. Versions below are the
resolved runtime packages in frontend/package-lock.json at the time of the
build. TypeScript-only @types packages and build-only Vite/TypeScript packages
are not part of the production JavaScript closure.
