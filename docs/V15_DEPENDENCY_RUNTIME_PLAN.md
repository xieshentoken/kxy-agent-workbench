## 3. 检查与缓存

新增少量SQLite记录：skill ID+内容hash+依赖声明hash+Agent/runtime配置指纹+检查器/上游版本→结果、checked_at、expires_at、耗时、cache_hit、失效原因。指纹包含平台/架构、解释器及CLI解析后的文件身份/版本、参与工具真实路径/文件身份、运行环境影响项的无密钥信息。凭据只用绑定ID/配置版本/变量存在性，不持久化密钥、密钥哈希或完整环境/原始输出。若PATH、CLI/解释器、依赖声明、Skill内容或检查器版本变化则失效。内容不可变快照沿用已有hash守卫，别每次复制Skill或创建环境。

成功结果默认24h有效，失败/未知短缓存约60s；手动重查强制绕过。并发相同请求合并或短锁避免重复探测；只限当前挂载的Skill，不扫描全盘。缓存数量有上限/保留期及清理入口，仅清检查记录，不能删原Skill、产物、历史运行。呈现缓存来源/时间/到期/待确认项，不把静态present、人工confirmed标成真实运行通过。

自动检测：设置增加挂载后自动检查开关（默认开）；分析器挂载/切Agent/runtime后检查当前选择集合，空挂载不检查。检查须非阻塞UI；结果按节点+Agent+所选集合关联，过期返回不能覆盖新选择。手动检查/强制重查始终可用；全局有检查记录查看及清理入口。检查结果不改变挂载选择。已有挂载节点再次打开时可读缓存/自动检查，切开关不会调用模型。

检查分层：SkillHub静态依赖；kxy可信已安装工具的有限版本探针。自动流程不能执行来自SKILL.md的shell命令、用户自定义检查脚本、npm安装/下载、MCP服务启动或未知Python模块import（import本身可执行代码）。只对明确可信的固定探针执行；其余显示需确认/未验证。MCP本轮复用配置/环境引用，报告command/解释器和变量缺项，真实服务握手需显式用户操作，不要伪报已握手。禁止为了通过检查自动补装依赖。高级锁文件/uv环境安装可保留为后续准备能力，README明确本轮尚不自动创建依赖环境。
