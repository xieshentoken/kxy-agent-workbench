# V7：Keychain 修复、批量选择、预设列表与动效强度

用户已授权实现，沿用既有 Luna max 任务。父任务诊断、独立验收及发布；不改变 WhatFa、用户原生 CLI 配置或历史安装包。

## 已定位的问题

macOS `security error 100001` 返回 `UNIX[Operation not permitted]`。父任务通过相同 Security.framework 调用，使用唯一随机合成条目进行对照：受限执行环境写入返回 100001；正常本机权限写入、读取匹配、删除均返回成功。当前正式服务继承了受限启动环境。修复为以正常本机权限启动 kxy 服务；分析器原有文件/网络沙盒仍保留。对 100001 提供准确说明，不能误报为 key 错误或仅要求解锁。禁止明文降级、修改 Keychain ACL、自动提权或规避沙盒。

## 最小实现

1. 原有 Keychain 读写函数复用简短错误解释，区分受限启动、锁定/交互问题与其他 OSStatus。README 说明在本机终端运行 `./start.sh` 或 `Start.command`。不在启动时自动写测试条目。
2. AI 服务目录连接成功后不自动勾选新发现模型。保留此前用户明确选择和编辑已有服务的选择。全选/反选作用于当前搜索可见模型，隐藏选择不变，按钮说明范围。
3. 输出容器的真实文件扩展名全选/反选；正文副本格式也独立提供同类操作，避免混淆两个许可范围。空选择保持合法。
4. 预设库列出全部已保存 analyzer 预设，可滚动、展开配置、明确应用与删除。处理旧请求覆盖新保存预设的竞态；新建预设不能因节点配置里残留 id 覆盖另一个快照。模型配置不自动冒充 analyzer 预设。
5. 外观 `motion_intensity` 整数 0–100，默认 100 保持原动效。滑块实时作用于鼠标拖尾和选中扩散强度；0 不计算高亮，开关关闭或 reduced-motion 仍优先。保存默认、刷新、恢复默认和服务端校验贯通，保持真实网格坐标。

修改现有文件，不引入新架构层。实现前备份，只构建 `frontend/dist-v7`。父任务验收后备份正式 SQLite/旧静态文件并发布，保留原始资料和原列数据。

## 验收

- 真实 Keychain：唯一合成 key 的写/读/更新/清理，只有状态和布尔结果入证据；绝不显示真实已有 key。不以 mock 通过替代此次 Keychain 结果。
- 后端：强度边界、默认/持久化、多个预设及残留 config.id、Keychain 错误和不落假记录；V6/V5 相关回归。
- 隔离浏览器：模型目录全不选、搜索后全选/反选、空列表；文件和正文批量选择及导出；多个预设保存/展开/应用/刷新；初始化竞态；强度 0/低/高与 reduced-motion、网格对齐及保存刷新。
- 正式进程使用正常本机启动权限；原数据校验、实际 HTTP 构建校验和测试进程清理。无真实提供商推理，无安装包重制。
