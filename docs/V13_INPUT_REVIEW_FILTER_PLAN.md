# V13 输入、过滤与人工审阅

用户已同意合并输入、改进人工确认/条件分支，并增加文件过滤器；本轮授权实施，Luna max 实现，父任务验收。不改 Pi 或外部 CLI 配置，不进行真实模型调用。

## 最小落地范围

1. 组件库只显示一个「输入」入口，复用 input 类型：text + files（file_id、relative_path/display name 的有序列表）。支持文本和多附件同时使用、追加/移除/选择文件与文件夹，文件夹选中后形成一张卡；资料库/运行快照继续按内容寻址。保留 file/text 旧流程兼容，不批量改写旧文档。文件夹相对路径是展示/匹配元数据，不能作为任意本机路径访问权。预设不得丢失文本/列表，也需提示缺失文件引用。黑盒 subflow_input/output 不合并。
2. 新增 filter 节点：文件名默认 *、扩展名默认 *。默认模式为 glob（*.pdf / *介绍*），另可选择正则搜索模式。名称匹配默认文件 basename；可显式选择文件夹相对路径；格式多选+自定义安全扩展名列表（大小写不敏感、支持 .pdf/pdf/*.pdf 输入规范化）；名称与格式取交集。筛选包括嵌套 source file 与 agent artifact，重建可达输出避免被过滤的附件从 items/upstream/inputs/excluded_artifacts/旧text摘要绕过；源文本说明可以保留，但被过滤文件的解析正文不可继续传递。输出保留匹配资料元数据，显示匹配数/排除数/列表；空匹配报明确错误，不默默以全部文件继续。过滤不删除原文件，不影响其他分支，不修改上游。用户追加明确：仅筛选传给下一个组件的文件；被拦下的文件仍保留原位置，禁止删除/移动/改写；界面明确说明，验收检查原文件存在和哈希不变。正则语法错误和执行超时应明确报错；使用现有可用 regex timeout 或有界子进程，不允许灾难回溯卡住服务。预览与运行用同一规则；预览优先画布已知附件、可用上游运行结果。
3. 人工确认升级可读审阅：正文完整可滚动显示；结构化原始数据可折叠；原有下载路径校验下的附件链接；自定义检查说明。保留通过、终止（兼容旧 reject），增加退回修改。允许显式开启编辑副本，保存 revision 与原始输入，人工修订只影响其后继，不覆写原输入或文件。备注清晰区分修订文本。通过输出包含原始溯源但下游主要 text/content 应是修订正文；避免正常正文中仍夹旧答案。退回只能绑定在有界循环内（不新增任意图回边）：反馈进入下一轮，消耗既有轮数/活动预算，循环审阅决策尊重人工退回；不在受支持循环位置时按钮禁用并说明放置规则。普通 DAG 上仍可通过/终止。确保不是把退回当作停止或假装通过；终止禁止继续下游。沿用原审批持久化和等待逻辑，拒绝重复决定，重启/续跑无自动放行。
4. 条件分支：字段手填保留，同时给上游结果字段列表及当前值预览（说明样本来源，无运行时显示暂无样本）。缺失字段策略 error（默认兼容）/false/true 显式选择；exists 保持存在性判断。多输入仍提示先汇总，不扩展表达式/eval/自动模型判断。不把类型错误当作缺失。
